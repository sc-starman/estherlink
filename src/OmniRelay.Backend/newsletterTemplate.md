We're excited to announce the release of **OmniRelay 2.1.24**, one of the biggest updates yet for performance, flexibility, and stealth networking.

This release introduces a completely upgraded multi-relay architecture, new modern protocols, enhanced client management, and major improvements across the platform.

## 🚀 What's New in OmniRelay 2.1.24

### Multi-Relay & Multi-Protocol Deployment

You can now deploy multiple relays and protocols on a single machine with a single license, each running independently with its own networking configuration.

This makes large-scale deployments cleaner, more flexible, and easier to manage.

### New Advanced Remote Protocols

Support has been added for modern stealth-focused protocols including:

* Hysteria2
* Naive
* ShadowTLS
* Trojan
* VLESS TLS

These protocols are designed for improved reliability, compatibility, and censorship resistance.

### Enhanced Privacy with DoH DNS Tunneling

DNS-over-HTTPS (DoH) tunneling is now the default and only supported DNS mode for stronger privacy and secure DNS resolution.

Additional secure DNS technologies are planned for future updates.

### SOCKS & HTTP Proxy Support

Added native SOCKS and HTTP support for broader device and application compatibility.

### Per-Client Speed Limiting

You can now apply bandwidth limits per client across supported protocols:

* VLESS
* Shadowsocks
* Trojan
* OpenVPN
* IPsec

### Improved Stability & Reliability

This update also includes:

* Improved local gateway relay stability
* More reliable client import/export
* Enhanced cleanup and validation functions
* Offline support for lifetime licenses after activation
